# HMP-2019 data analysis: Using ssTaxSEA to investigate oral colonisation of IBD patients.
TaxSEA is a tool that can infer important taxon sets from differential abundance analysis. ssTaxSEA can single out the specific subjects or patients that have presence of the taxa from those important taxon sets. This script run both on HMP-2019 to investigate the presence of oral bacterial in the gut.
