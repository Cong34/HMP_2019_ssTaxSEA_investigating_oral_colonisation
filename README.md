# Investigating Oral Colonization in IBD Patients: HMP-2019 Data Analysis with ssTaxSEA

## Overview

This project uses **ssTaxSEA** to analyze oral microbiota composition in inflammatory bowel disease (IBD) patients from the Human Microbiome Project (HMP-2019) dataset. TaxSEA is a powerful tool that identifies important taxon sets from differential abundance analysis. ssTaxSEA extends this capability by identifying specific subjects and patients who harbor these taxa, enabling personalized microbial profiling.

### Project Goals

- Investigate the important taxon sets and taxa that are associate with IBD.
- Create a time series that show how stable oral colonisation is. 

## Dataset

This analysis utilizes the **HMP-2019** dataset, focusing on oral microbiota samples from IBD patients.
It also include a script for **HMP-2012** dataset, which are used to investigate differential abundance between oral and gut microbiome. 

## Tools & Technologies
- **TaxSEA** and **ssTaxSEA**: Subject-Specific TaxSEA for individual-level taxon set analysis
- **LinDA**: Differential abundance analysis
- **R**: Data processing and visualization
